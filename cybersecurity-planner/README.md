# Configurator App

A modern React app to configure deployments, built with Material UI and advanced routing logic.

## Features
- Auth system with redirect logic
- Dark/Light mode toggle
- Role-based UI elements
- Voice-to-GPT integration (planned)
- Styled with Material UI and custom components

## Getting Started
```bash
npm install
npm run dev
```
