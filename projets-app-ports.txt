---------- BASE DE DONNÉES ----------
6) gantt-db (postgres)
   Hôte        : (volume persistant Docker `gantt_pgdata`)
   Container   : /var/lib/postgresql/data
   Image       : postgres:16-alpine
   Ports       : 3232:80
   Connexion   : postgres://app_srv_gantt:<password>@localhost:3232/gantt_dev


=========================================
 NOTES
=========================================
- Les frontends Vite exportent des fichiers statiques copiés dans /usr/share/nginx/html
- Le backend Node utilise /app pour exécuter le serveur
- La base PostgreSQL stocke ses données dans un volume Docker accessible en local
- Un reverse-proxy (Traefik / nginx / Caddy) peut unifier les URLs en prod
- Le monorepo permet un pipeline CI/CD unique
